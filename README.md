# Анализ фитнес-активности FitBit (Прикладное цифровое решение)

Прикладное решение на Python, которое превращает исходные данные фитнес-трекера FitBit в понятный недельный отчёт. Программа анализирует вашу активность, выявляет скрытые паттерны, рассчитывает личные цели и визуализирует результаты в удобном графическом виде.

## Функциональные возможности
- Интерактивный выбор пользователя: при запуске программа выводит список доступных ID с количеством дней активности, позволяя выбрать конкретного клиента для анализа.
- Предобработка данных: автоматическое приведение дат к единому формату, обработка пропущенных значений, фильтрация аномальных выбросов (например, шагов > 60 000) и объединение таблиц по ID и дате.
- Расчёт метрик: вычисление дневных сводок, 7-дневного скользящего среднего (MA7), индекса регулярности активности (на основе коэффициента вариации), времени в зонах интенсивности (в часах) и персональной цели по шагам (на основе 75-го перцентиля личной истории).
- Поиск паттернов: построение тепловой карты активности (день недели × час суток), детекция аномальных дней на основе устойчивой к выбросам медианы (MAD) и корреляционный анализ влияния сна на активность следующего дня.
- Генерация отчёта: формирование текстового резюме с логикой на основе правил (сравнение текущей и прошлой недели, профилактика перетренированности, рекомендации по сну и сидячему образу жизни).
- Визуализация и выгрузка: построение интерактивных графиков (matplotlib) с их автоматическим сохранением в формате PNG в персональную папку выбранного пользователя.

## Установка и запуск
1. Убедитесь, что у вас установлен Python версии 3.9 или выше.
2. Установите необходимые зависимости, выполнив в терминале команду: `pip install -r requirements.txt`
3. Скачайте датасет FitBit Fitness Tracker Data с Kaggle (ссылка: https://www.kaggle.com/datasets/arashnic/fitbit?select=mturkfitbit_export_3.12.16-4.11.16) и распакуйте архивы так, чтобы 5 CSV-файлов лежали в папке `data/`.
4. Запустите главный скрипт командой: `python main.py`
5. Следуйте инструкциям в консоли: выберите номер пользователя из предложенного списка. После этого программа последовательно рассчитает метрики, выведет текстовый отчёт, откроет окна с графиками (их нужно будет закрыть) и сохранит все результаты в папку `output/user_<ID>/`.

## Структура проекта и описание файлов
Проект организован по модульному принципу для удобства поддержки и масштабирования. Корневая папка проекта `fitbit_analytics` содержит следующие файлы и директории:

- `__pycache__/` — системная папка, автоматически создаваемая интерпретатором Python для хранения скомпилированных байт-кодов. Удалять её вручную не требуется.
- `data/` — директория для хранения исходных данных. Сюда необходимо поместить 5 скачанных CSV-файлов: `dailyActivity_merged.csv`, `hourlySteps_merged.csv`, `hourlyIntensities_merged.csv`, `minuteSleep_merged.csv` и `weightLogInfo_merged.csv`.
- `output/` — директория для результатов работы программы. Внутри неё автоматически создаются персональные подпапки для каждого проанализированного пользователя (например, `user_1503960366/`), в которых сохраняются текстовый отчёт `report.txt` и графики `1_steps_dynamics.png`, `2_zones.png`, `3_activity_heatmap.png`.
- `main.py` — главный исполняемый файл (точка входа). Отвечает за оркестрацию всего пайплайна, интерактивное меню выбора пользователя, последовательный вызов функций из других модулей и корректное сохранение файлов по нужным путям.
- `data_loader.py` — модуль загрузки и предобработки. Отвечает за чтение CSV-файлов, приведение форматов дат (с обработкой разных форматов во избежание ошибок парсинга), заполнение пропусков, фильтрацию выбросов и объединение таблиц активности, сна и веса.
- `metrics.py` — модуль расчёта метрик. Содержит функции для вычисления 7-дневного скользящего среднего, индекса регулярности, подсчёта минут по зонам интенсивности, определения максимальной серии активных дней и расчёта персонализированной цели.
- `patterns.py` — модуль аналитики паттернов. Реализует сводную матрицу для тепловой карты, поиск аномальных дней с помощью робастного Z-score (медиана и MAD) и расчёт корреляции между сном и шагами следующего дня.
- `report.py` — модуль генерации отчёта. Превращает числовые метрики в понятный текст с логикой на основе правил, добавляет рекомендации и корректно обрабатывает случаи отсутствия данных (например, если у пользователя нет браслета для отслеживания сна).
- `visualization.py` — модуль визуализации. Строит графики (динамика шагов, зоны интенсивности в часах, тепловая карта), открывает их в интерактивном окне и автоматически сохраняет в формате PNG в папку пользователя.
- `test_app.py` — модуль тестирования. Содержит юнит-тесты для проверки корректности математических алгоритмов (регулярность, цели, аномалии, корреляция) и интеграционный тест, проверяющий успешную загрузку реальных CSV-файлов.
- `requirements.txt` — текстовый файл со списком внешних зависимостей (pandas, numpy, matplotlib), необходимых для установки окружения.

## Тестирование и проверка
В проекте реализовано тестирование для контроля работоспособности. Запустить тесты можно командой `python test_app.py` (или `python -m pytest test_app.py`). Юнит-тесты проверяют граничные условия алгоритмов (например, что цель по шагам не может быть меньше 5000 или больше 20000), а интеграционный тест проверяет, что пайплайн чтения данных отрабатывает без ошибок на реальных файлах. В случае отсутствия папки с данными интеграционный тест корректно пропускается.
